# Yamamo Shop

Yamamo Shop เป็นโปรเจกต์เว็บไซต์ร้านค้าดิจิทัลสำหรับ Roblox ที่พัฒนาเพื่อใช้เป็นผลงานใน Portfolio โดยเน้นการออกแบบ UX/UI, Frontend Interaction และ User Flow ของระบบร้านค้าออนไลน์

## ฟีเจอร์หลัก

- Responsive Web Design สำหรับ Desktop และ Mobile
- Product Catalog พร้อม Search, Filter และหลายหมวดสินค้า
- หมวด Roblox Toy Code, Robux, Gamepass และ Farming Service
- โครงสร้างหมวดบริการแบบหลายชั้น เช่น Farming Service → Fisch → รายการบริการ
- Shopping Cart เพิ่ม/ลดจำนวนสินค้าและคำนวณยอดรวมแบบ Real-time
- Checkout Flow แบบ Demo
- Order Status พร้อมเลขออเดอร์และ Progress Status
- Top-up UI สำหรับ QR Code, ซองอั่งเปา และ TrueMoney Wallet แบบ Demo
- Login / Register UI รวมอยู่ใน Account Modal เดียว
- Sold Out และ Coming Soon states
- FAQ และ Facebook Contact section
- Animation, Hover Interaction และ Scroll Reveal
- ใช้ LocalStorage สำหรับตะกร้าและ Order Demo

## เทคโนโลยี

- HTML5
- CSS3
- JavaScript
- Responsive Design
- LocalStorage
- UI/UX Design

## หมายเหตุ

ระบบ Login, Payment, Top-up และ Order Processing ในโปรเจกต์นี้เป็น UI/Frontend Demo สำหรับ Portfolio เท่านั้น ยังไม่มี Backend, Database หรือการรับชำระเงินจริง

## จุดประสงค์ของโปรเจกต์

โปรเจกต์นี้ใช้แสดงทักษะด้าน Web Development, UX/UI Design, Responsive Design, Interactive UI และการออกแบบ Workflow ของ E-commerce Web Application
